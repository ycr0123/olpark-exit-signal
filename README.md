# 올팍 출구 신호등

공연 날 밤, 지금 나가도 될지 알려 주는 올림픽공원 주차 출구 안내입니다. 2026년도 한국체육산업개발 공공데이터 활용 경진대회 응모작입니다.

- 시연: https://ycr0123.github.io/olpark-exit-signal/
- 화면은 기관 실시간 주차현황 API(공공데이터포털 15168686)를 브라우저에서 5분마다 직접 부릅니다. 서버와 개인정보 저장이 없습니다.
- `.github/workflows/record-live.yml` 이 5분마다 같은 API를 한 번 불러 `live` 브랜치의 `recent.json`(최근 4시간)을 덮어씁니다. 처음 연 사람도 30분 변화를 바로 보게 하려는 장치입니다.

## 파일

| 경로 | 내용 |
|---|---|
| index.html | 시연 화면(지금, 공연 날 밤 다시 보기, 2025년 기록, 운영자) |
| data.json, facts.json | 2025 입출차 재집계와 시험 결과(analysis/build_demo_data_v03.py 가 생성) |
| schedule.json | 기관 누리집 공연 일정 목록에서 읽은 공연 기간 |
| tools/record_recent.py | 실시간 값을 받아 최근 4시간 기록을 갱신 |
| analysis/ | 수집, 결함 점검, 재집계, 사전 등록 시험, 기획서 수치 산출 스크립트와 그 결과 |

## 분석 순서

1) `kcisa_collect_v02.py`: 문화공공데이터광장에서 2025 입출차(15159093)와 연계 데이터(15164822)를 받습니다. 키는 직접 발급받아 `private/kcisa-keys.txt` 에 두어야 합니다.
2) `build_trips_cache_v01.py`, `coverage_v01.py`: 차량 한 대를 한 행으로 묶고, 날짜별 건수로 잘린 날(65,535건 안팎에서 끊긴 달, 매달 마지막 날 0건)을 찾습니다.
3) `kcisa675_events_v01.py`: 연계 데이터에서 공연 기록이 있는 날과 관람객 기재값을 뽑습니다.
4) `exit_after_show_v03.py`, `verify_h2_v02.py`, `verify_gate_v01.py`: 상반기에서 정한 규칙을 하반기 결함 없는 날로 시험합니다. 통과선은 각 스크립트 맨 위에 있습니다.
5) `plan_facts_v02.py`: 기획서와 화면의 모든 수치를 한 파일(plan_facts_v02.json)로 냅니다.

원자료(약 241만 건)는 용량 때문에 올리지 않았습니다. 위 1)로 다시 받을 수 있습니다.
